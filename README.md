# 📊 Bank Loan Analysis Dashboard

## Project Overview

This project analyzes bank loan data to uncover trends, repayment behavior, loan performance, and risk factors that help financial institutions make data-driven lending decisions.

The solution was developed using Excel, SQL, Power BI, and Tableau to transform raw loan records into actionable business insights.

---

## Business Problem

Banks process thousands of loan applications every year. Identifying high-risk borrowers and understanding repayment patterns is essential for reducing defaults and improving profitability.

This project provides a comprehensive analysis of:

- Loan applications
- Funded amounts
- Loan repayments
- Borrower profiles
- Risk indicators
- Good vs Bad loans

## Key Insights

### Good Loans

- 85.8% of loans are classified as Good Loans
- Generated $377.5M in funded amount
- Returned $444.2M in payments

### Bad Loans

- 14.2% of loans are classified as Bad Loans
- Generated $68.1M in funded amount
- Returned only $38.5M

### Risk Findings

- Verified borrowers show stronger repayment behavior
- Higher loan grades carry increased revolving balances
- Debt consolidation loans dominate loan applications
- Mortgage holders receive the largest funded amounts

---

## Business Recommendations

- Prioritize verified borrowers
- Monitor high revolving balance grades closely
- Strengthen risk checks for bad loan categories
- Use KPI-driven monitoring to improve lending decisions
